## Schedule "A" — Description of Assigned Technology & Intellectual Property Assets

1. **Core Software Platform & Source Code Repository (`Quotelytics`):**
   - Full Python / FastAPI multi-tenant backend application (`main.py`, `services/`), SQLite WAL database engine and schemas (`services/db_service.py`, `services/quotelytics_db_service.py`), deterministic LTL CWT/skid and deficit-rating engine (`services/quotelytics_rating_engine.py`), Excel/CSV carrier tariff ingestion and human-in-the-loop cell-coordinate verification pipeline (`services/quotelytics_extractor.py`), Stripe CAD subscription and webhook billing service (`services/stripe_service.py`), and CASL/PIPEDA compliance audit trails.
2. **Frontend Console & Public Web Templates:**
   - All HTML5/Jinja2 templates (`templates/`), responsive CSS stylesheets (`static/css/`), and client-side JavaScript modules (`static/js/`).

   - Systemd service specifications (`quotelytics.service`), Nginx reverse-proxy and Canadian data-residency header configurations (`nginx_quotelytics.conf`), automated SQLite hot-backup scripts (`backup_db.sh`), and Ubuntu LTS server provisioning scripts (`setup_whc_server.sh`).
4. **Domain Name, Trademarks & Commercial Documentation:**
   - Domain name **`quotelytics.ca`** and all subdomains (`www.quotelytics.ca`, `api.quotelytics.ca`).
   - All rights and goodwill in the trade name and trademark **"Quotelytics"** and **"Quotelytics Inc."**
   - All customer help-centre documentation, legal policies (MSA, Privacy Policy, DPA, Subprocessor Directory), and commercial sales playbooks.
